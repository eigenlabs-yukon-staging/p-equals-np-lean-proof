# Deterministic sparse assignment search below unit clause weight

This submission gives a measured assignment algorithm for canonical CNFs whose dyadic clause weight is strictly below one, assuming each clause uses a variable at most once. It also gives a measured test for that domain. The input is the ordinary encoding of the pinned reference, with natural-number variable identifiers represented in binary. The output is the concatenation of the reference variable encodings for the variables assigned true. All other variables are assigned false. The search theorem explicitly proves that the output is such an encoding, every emitted identifier occurs in the input, and the assignment obtained from the output satisfies the input. The domain includes formulas of arbitrary clause width, and the algorithm's iteration count depends on encoded size, which matters when just one variable has a large identifier.

The principal declarations are `PEqualNP.Outside.MeasuredLowWeightSearch` and `PEqualNP.Outside.ExactLowWeightSAT`. The first is a search guarantee on a promised class. The second is a language membership theorem against the pinned definition of `P`. Its language consists of precisely the canonical encodings that have distinct variables within every clause, have weight below one, and are satisfiable. The proof explicitly derives satisfiability from the guard using the measured search theorem. The language excludes malformed strings. The weight criterion is sufficient for satisfiability on this domain. It is not necessary for satisfiability in general, and this package does not decide unrestricted SAT, prove `NP ⊆ P`, or settle P versus NP.

## The weight test and its runtime

For a formula with clause widths at most `n`, let the bin at `i` count the clauses of width `i`. The weight is the sum of these counts times `2⁻ⁱ`. `ClauseWeightCarry` formalizes the equality of the rational weight calculation and the histogram mass calculation. At every step in descending width order, the integer carry adds the current bin to the previous carry divided by two with floor rounding. The proof tracks a rational value in the half-open interval from the integer carry to that carry plus one. At width zero, the carry is zero exactly when the weight is strictly below one. The equality case at weight one therefore rejects.

`MeasuredClauseMap` supplies a generic concatenation wrapper for polynomial-time clause transformers with a shared argument. Its parser extracts a first clause and remainder from every raw input, with a length bound on that remainder even for malformed strings. For canonical input the parser result agrees exactly with the clause boundary. The wrapper enumerates at most the raw input length's worth of suffixes, and the result on a canonical formula is the flat-map over its clause list. Empty clauses are preserved as clause inputs until the encoded formula itself is exhausted.

`MeasuredWidthClassCount` instantiates the wrapper using the earlier measured clause literal counter. Widths and counts are represented in unary, while variable identifiers retain their canonical binary codes. The search does not construct the rational denominators. `MeasuredClauseWeight` calculates the histogram implicitly, from the raw encoding length down to zero inclusive. It uses the square of the length plus one as a bound on the stored accumulator. An invariant bounds the current accumulator plus the number of remaining rounds times the clause count. This establishes that clipping is inert for canonical inputs and keeps intermediate states bounded on every raw input. The bounded iterator supplies the reference polynomial-time proof.

## Assignment search and correctness

`MeasuredVariableRestriction` gives two assignment modes and one erasure mode. For assignment mode it removes each clause that contains the selected signed literal and removes all occurrences of the selected variable from every surviving clause. For erasure it removes the occurrences without dropping any clause. Codes are compared at literal boundaries. The statements are formulated on the ordinary canonical CNF, and the runtime proofs are for total raw bit-string operations.

For nonempty low-weight formulas the first clause contains a literal, since an empty clause contributes one and all clause contributions are nonnegative. Use the variable of the first literal, test the positive restriction, and choose true if its weight remains below one. Otherwise choose false. The pinned inequality `wt_restrict_le` implies that one branch always stays below the threshold, since the sum of the two restricted weights is at most twice the original weight. Restriction also preserves distinct variables in each clause. Each reduction strictly decreases the encoded length because the first clause either disappears or loses its first literal. The solver can therefore run for the input's encoded length, leaving an empty formula in place for surplus rounds. This avoids iterating through the numerical range of the identifiers.

The implementation keeps the residual encoding and an accumulator of positive variable codes. The state budget is quadratic in the original encoding length. Each loop round adds a code of length at most the original encoding length, and only a true branch adds a code. A progress lemma proves the residual bound for both branch values. A separate correctness induction proves that every emitted variable comes from the original residual formula and that it cannot equal the just-removed identifier when produced by a later round. This freshness argument makes membership in the accumulated sparse list agree with the selected value at each restriction step, even for a variable whose chosen value is false. Lifting satisfying assignments from the restriction then proves the original formula is satisfied.

The exact language guard checks canonical syntax using the pinned parser. It checks distinctness by looking for either polarity of each literal's variable later in the same clause, and checks weight via the measured histogram carry. The proof establishes the guard in both directions against the canonical formulas. For example a clause containing both polarities of one variable is outside the distinctness guard, even if that clause is tautological. The empty formula is in the language.
