# Polynomial-time verification of bounded Davis–Putnam elimination orders

This submission closes the size-bound and stage-checking gaps left by the single-step Davis–Putnam construction. It implements an exact deterministic polynomial-time walk on a canonical formula, a variable order, and a finite list of candidate clauses. A second theorem places the corresponding accepting language of canonical triples in reference P. At every step a formula is compared extensionally as a set of finite-set clauses. Clause and literal order, and both kinds of repetition, therefore do not affect whether a stage is covered. A fixed-width specialization constructs its candidate list from the original signed literal support and needs only the formula and the proposed order.

## Covered stages and the output convention

The step eliminates one pivot by preserving clauses containing neither pivot polarity, taking exact resolvents of pairs of opposite single-polarity parents, and discarding clauses containing both pivot signs. Its semantic preservation theorem proves equisatisfiability by updating only the pivot value on a model of the result. That theorem is reused unchanged. The new walk verifies whether every prefix of the specified order produces a stage contained in the supplied universe as a set of clauses. The empty prefix is included, so the original clauses must also be represented. The full prefix is included, so the final stage must remain within the same bound.

The coverage test relies on a measured finite-set subset check. The prior intersection machine filters universe entries by whether each finite-set clause is represented in the other formula. Reversing the inputs filters the candidate formula itself by universe membership. Equality between that filtered canonical CNF word and the original candidate word holds exactly when every candidate entry survives. The proof uses canonical CNF encoding injectivity and exact correctness of the finite-set clause comparison. Each covered stage may consequently be replaced with a sublist of the fixed universe representing exactly the same finite-set formula.

A successful walk returns a leading true bit followed by a canonical encoding of its final stage. The marker distinguishes successful empty CNF from failure. The empty output word means that at least one elimination stage fell outside the available universe. In particular a satisfiable formula may produce the failure word if the chosen order or universe does not satisfy the stage condition. A final stage containing an empty clause encodes that clause's delimiter, so it does not get confused with a final stage containing no clauses.

## Clock and state bound

A state contains the immutable supplied universe, the remaining positive-literal representation of the order, the stored current CNF, and a validity flag. The raw transition is measured by the prior single-step eliminator, set inclusion and intersection, plus the pinned bitstring operations. If the current state is valid and the remaining order has another literal, it computes the next stage, tests its inclusion, and chooses representatives from the supplied universe. An invalid state freezes. A completed state also freezes. This gives a well-defined raw machine on all input words.

The machine runs for the encoded order length, which dominates the number of pivots. Each enabled transition drops one encoded literal of the remaining order. The new stage code is clipped to the immutable universe’s encoded length. For canonical inputs this cap is inert, because the intersection result is literally a sublist of the universe. On arbitrary raw words the cap gives a per-round state growth allowance linear in the length of its immutable universe projection. The projection is unchanged on both the active and frozen transitions. The allowance is initially bounded linearly in the raw state. The pinned measured iteration theorem therefore yields polynomial time even for malformed raw words. The initial formula is part of the input size, and after the first enabled transition the current clause encoding is bounded by the universe. There is no use of unchecked input-dependent repeated composition of the one-step polynomial.

## Exact accepting language and satisfiability

The P theorem checks nested pair framing by splitting and re-encoding it, and checks every component for canonical CNF syntax. The variables in the order are supplied as the literal sequence obtained by flattening a canonical CNF word. The normalizer preserves each variable identifier and uses positive polarity regardless of the original sign. It works through measured literal and clause maps. This encoding supports repeated variables, empty lists, and arbitrary binary variable identifiers. The decider requires successful coverage and that the final stage contain no clauses. Its exact language theorem includes the rejection of strings that do not have the stated canonical triple syntax.

The pure full-order theorem connects the terminal condition to SAT. Every surviving literal comes from the original support and every eliminated variable stays absent. When the chosen order covers all original variables, the final stage can contain only the empty clause. Repeated equisatisfiability then makes absence of every final clause equivalent to satisfiability of the original formula. On a shorter order, reaching an empty final stage still implies satisfiability by repeated equisatisfiability. A shorter order can leave a nonempty satisfiable stage, so the accepting language uses the exact terminal condition. The verified coverage walk returns the actual stage on success and can also represent that case.

The fixed-width specialization generates all clause words of length at most a fixed k on the original signed support, using the earlier measured universe generator. An elimination step introduces no signed literal absent from its input. Consequently a stage is covered by this generated universe exactly when each finite-set clause has cardinality at most k. For the forward implication, choose the duplicate-free list of a finite-set clause. The reverse implication uses that a finite-set cardinality is at most the length of any representing list. The resulting measured route decides the width condition exactly on canonical formula and order inputs. When the order also covers the original variables, the successful run represents a satisfiable input exactly when it returns the singleton true marker. The theorem treats k as a fixed parameter and the order as supplied input. It provides no bound for finding such an order or for the width needed on arbitrary formulas.
