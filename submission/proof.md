# Locality-window clause universes with linear row count

This submission replaces the global fixed-width candidate universe used in the earlier locality witness algorithm with a smaller measured universe. For each start position in the input literal sequence, the new generator takes at most k plus one consecutive literals and includes both polarities of each variable. It emits all position subsequences of that signed window as candidate clauses. The exact Lean theorem proves a bound of one plus the number of input literal occurrences times two to the power of twice k plus two on the number of emitted canonical rows. The power depends only on the fixed locality radius k. A separate coverage theorem proves that the window universe includes a representative of every clause at every Davis–Putnam elimination stage for formulas satisfying the first-occurrence radius condition. The final measured theorem instantiates sparse model search using this generated universe.

## Building the catalogue

The measured suffix combinator generalizes the previous literal map. It invokes a fixed measured transformation on the encoded suffix from each literal boundary of a canonical clause and concatenates its outputs. Using the same literal parser and its measured iteration, it skips exactly one encoded literal at a time. The canonical clause delimiter does not produce a suffix result. This excludes the final empty suffix and gives one transformation per literal occurrence. The theorem states equality to a finite range scan over the actual list of suffixes.

The fixed-window operation consumes at most k plus one literals of its supplied suffix and outputs both signs of each corresponding identifier. On a shorter suffix the delimiter stops the operation before any padding entries are added. The proof retains the original binary identifier and uses the measured literal negation only on the sign. This is independent of the sign in the input occurrence. The resulting clause word is canonical and contains at most twice k plus two literal positions.

The bounded subsequence generator uses the include-or-exclude recurrence on a fixed prefix. For a nonempty prefix, it computes the encoded clauses for all subsequences of the remaining prefix. It copies those clauses once, and then prepends the current literal to each clause in a second copy. An empty prefix gives the single empty-clause row. The exact membership theorem uses the list sublist relation, so a row may preserve repeated input positions even though resolution stages are interpreted extensionally. Its number of output rows is exactly two to the power of the number of positions retained. This is an exact count with multiplicity, irrespective of repeated literals.

Composing these operations gives the measured catalogue. The generator starts with the empty clause and appends all bounded subsequences for each signed window. The empty clause is always represented, including for the empty input sequence. The measured machine is polynomial-time for each fixed radius on arbitrary raw input, and the exact row and membership bounds apply on canonical input. The result improves the candidate count compared with enumerating all words of a fixed width over the entire signed support. The theorem bounds the number of canonical rows, with a separate encoded-length cost for writing their variable identifiers.

## Why all relevant stages are represented

The coverage theorem starts with any original finite-set clause formula whose variables occur in the supplied occurrence sequence and whose co-occurring variable first ranks lie within radius k. The exact variable elimination operation retains neutral clauses and resolves opposite single-polarity parents. The earlier locality preservation argument ensures that every resulting clause still has the first-rank distance property. This archive factors that argument into a reusable theorem about each stage and retains the exact earlier cardinality statement. A literal that survives a prefix stage still occurs in the original formula and its variable has not been eliminated.

Take any nonempty stage clause and let i be the smallest first-occurrence index among its variables. For each literal in that clause its first occurrence is at least i and at most i plus k. Its variable therefore occurs among the input literal positions retained by the signed window starting at i. The proof uses the exact first-index lookup and handles shortened windows at the end of the sequence. Because both signs are present in the window, the specific signed stage literal occurs there regardless of the first occurrence's original sign. Filter the signed window by membership in the finite-set stage clause. The filtered list is a subsequence of the window and gives exactly the finite-set clause after repetitions are discarded. Its row is present by the measured catalogue's exact membership theorem. The empty clause case uses the explicit empty row.

This coverage is exact enough for the previously verified bounded elimination walk. It requires inclusion of the original stage and every subsequent stage, including the final one. The generator may contain additional clauses and repetitions. The walk checks actual membership only of clauses arising in a stage and represents them using the fixed catalogue. The argument does not require equality between the catalogue and the set of all clauses that actually arise.
