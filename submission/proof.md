# Componentwise SAT by measured variable co-occurrence

This submission proves a composition theorem for deterministic polynomial-time SAT procedures. Suppose a measured guard identifies a class of canonical formulas, and a measured SAT procedure is correct on that class. The composition theorem decides the exact language of satisfiable canonical CNFs for which every variable co-occurrence component is in that guard. The input remains the ordinary reference encoding. Neither a component partition nor representative variables are supplied. The archive specializes this framework to components that independently satisfy either the Horn condition or the polynomial-rank 2-CNF variable-deletion condition, and proves a measured sparse satisfying-assignment procedure for that hybrid language.

The hybrid class can contain formulas outside both global restrictions. For example, at a constant branch budget of one, put a three-literal all-negative Horn clause on one group of variables and a binary all-positive clause on a disjoint group. Both clauses together form neither a Horn formula nor a 2-CNF. The componentwise algorithm can handle the separate Horn and binary components. This example describes the scope of the construction. The development does not establish that arbitrary SAT instances split into components belonging to the guard, that unrestricted SAT lies in P, or that P equals NP.

## Exact components and the satisfiability factorization

Two variables touch if they both occur in some original clause. Their connection is the reflexive transitive closure of touching. Each query selects, in original order, the clauses containing a variable connected to the query variable. Repeated clauses remain repeated. All variables of a nonempty clause belong to one connected component, so the first literal of a clause is a valid representative for the complete component containing it. The sign of that literal does not affect component selection. An empty clause cannot be included in a variable component, so the original formula must be tested for it separately.

`CNFComponentFactorization` proves that a canonical formula is satisfiable if and only if it contains no empty clause and every variable component is satisfiable. Restricting a global satisfying assignment to the subset of clauses gives one direction. In the other direction the pure proof picks a consistent representative for each variable class and uses its component's satisfying assignment on that class. The representatives agree for connected variables, so all literals of a clause are evaluated according to the same local assignment. The measured algorithm later checks satisfiability using component deciders. It has no need to compute the pure proof's least natural-number representatives.

## A measured component extractor

`MeasuredLiteralMap` extends the earlier clause-level concatenation construction to canonical literal boundaries. It lifts a measured transformer on an encoded literal and a shared argument to one over all literals of a clause. The scan uses the raw clause encoding length as a bound and drops one complete literal per position. The clause terminator and surplus iterations cannot contribute outputs on a canonical input. The machine bounds its traversal even for arbitrary raw inputs.

`MeasuredVariableGraph` uses two nested literal scans and a clause scan. For each ordered pair of literal positions in a clause, with variable identifiers `u` and `v`, it emits the binary clause `[¬u, v]`. Both directions appear because the pairs are ordered, and repeated occurrences require no special cases. Positive-literal implication edges in the generated formula are exactly the touching relation. Positive seeds cannot reach a negative literal. The construction uses each variable's existing binary code and changes the polarity tag. Its nested loops remain polynomial in encoded size.

`MeasuredCNFComponent` computes the pinned complete implication closure on the generated binary formula, starting from the positive literal for the query variable. The proof invokes the reference bound on the number of rounds for that closure. It then filters the original clauses using membership of each clause's positive head variable in the computed closure. The binary formula is used purely as a graph representation for reachability. Its satisfiability is irrelevant. The extraction theorem identifies the result exactly with a filter of the original clause list, using the reflexive transitive closure of variable co-occurrence in its recorded statement. It includes the case where the query is an isolated variable with no clauses.

## Composition and sparse witness recovery

`ComponentwiseSAT` accepts a guard language and a SAT language in the reference P class, together with a proof that the latter agrees with satisfiability on the former for canonical inputs. It tests both at each extracted component and rejects if any clause yields a failure. It explicitly rejects an empty clause and accepts the empty formula. Repeated extraction of one component is possible when there are several clauses in it. The measured finite scans still give a polynomial-time algorithm, and the code does not depend on an unverified deduplication procedure. The pinned canonical syntax guard rejects malformed bit strings. The final equivalence quantifies over every literal in every clause, while the measured scan checks just a clause's head, because connected seeds select the same component.

`ExactComponentwiseHybridSAT` instantiates the theorem with the union of the exact Horn and variable-deletion guards. Every component gets its own choice of solver. The deletion budget is evaluated at the component's encoded length, and its proof uses a witness of size at most some `k` with `6^k ≤ q(componentLength) + 1` for a fixed natural-coefficient polynomial `q`. The base language uses the union of the exact satisfiable guarded classes. Nothing requires all components to choose the same guard branch.

`ComponentwiseHybridSATSearch` invokes the measured sparse search with this new exact language. Appending unit constraints adds only self-edges to the co-occurrence graph, so it cannot merge connected components. Every old component retains its original clauses and gains at most some of the appended units. An added unit remains Horn and stays at width at most one after variable deletion. The natural polynomial budget is monotone as the component's encoded length grows. A component formed only from new unit clauses is Horn. These facts prove that all appended-unit queries stay in the domain, which is the premise required for the measured sparse witness construction. The output encodes only variables assigned true and has length at most the original canonical input.
