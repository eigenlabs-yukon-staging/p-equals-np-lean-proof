# A generic measured solver for fixed-size variable deletion

This submission formalizes exact deterministic polynomial-time algorithms for deleting a bounded number of variables into a tractable guarded class. Given a measured guard and a measured SAT decider correct on its canonical guarded inputs, assume the guard is closed under sublists of clauses. The new solver recognizes the exact class of canonical CNFs with a deletion set of size at most a fixed `k`, and decides satisfiability of the original CNF on that class. The deletion set is discovered internally. Deletion here removes literal occurrences while retaining clause positions. It is a separate operation from setting the variable to a Boolean value, which may drop satisfied clauses.

The archive gives two concrete instances. The target guard can be either Horn or renamable Horn. For the renamable guard, a valid deletion set leaves a single global sign renaming with at most one positive occurrence in every remaining clause. The deleted variables can occur arbitrarily often and original clauses can have arbitrary length. There are separate exact language theorems and sparse satisfying-assignment constructions in both cases. This is a restricted SAT result. It does not claim the existence of a fixed deletion bound for arbitrary CNFs or a polynomial-time decision procedure for unrestricted SAT.

## Generic completeness and the paired invariant

The pure deletion recurrence is independent of the target class. If a deletion list of size at most `k+1` reaches the guard, consider whether the list contains any variable occurring in the original formula. If it does not, the literal filter removes nothing, so the formula is already guarded. Otherwise any such occurring variable can be moved to the front of the deletion list. The proof removes one occurrence of its identifier from the witness list and shows the same filter results from erasing that variable and then erasing the remaining list. The reverse direction prepends the chosen identifier to a witness from the child. The argument permits duplicate identifiers and avoids a numerical bound on variable indices.

At every node the algorithm has a structural CNF `φ` and a residual CNF `ψ` that is a sublist of `φ`. For each literal occurrence in `φ`, the algorithm considers its identifier. On the structural side it erases all occurrences of that identifier, keeping clause positions. On the residual side it separately tries both Boolean assignments. Both children preserve the sublist invariant because the residual operation filters away satisfied clauses before applying the same literal filter as the structural operation. The rule does not need structural membership to be preserved by variable erasure. It only needs the stated sublist closure so that when the structural CNF belongs to the guard, the residual formula can use the base solver.

Satisfiability of any residual formula is equivalent to satisfiability of some one-variable restriction. One direction chooses the value in an existing assignment and verifies every surviving clause. The other direction updates a residual satisfying assignment at the chosen variable and lifts it to the parent. This equivalence is separate from the structural deletion test. If the structural guard is already satisfied and the residual is satisfiable, the base branch succeeds. Otherwise the algorithm considers further variables when the depth permits. The mathematical recurrence permits exploring all such representative literal occurrences, including repeats and both signs.

## Measured search and exact languages

The paired raw machine uses the measured literal and clause scans. Each of the fixed number of levels examines only the literals in the current structural formula, not all numbers up to the largest identifier. It passes the current paired input as a shared argument, then uses the measured assignment and erasure transducers on the selected identifier. The two children emit nonempty markers for success. Concatenation and a test for nonemptiness implement the existential over those branches. The recursive proof constructs a machine for each fixed `k`; it does not assert a uniform polynomial degree for an encoded arbitrary bound. With fixed depth, these scans, raw encodings and finite compositions are polynomial in the pinned model, including on malformed raw strings.

`MeasuredVariableDeletionSAT` states the paired specification against the reference `ComputableInPolyTime`. On canonical input, success is equivalent to a deletion set of the specified size for the structural formula and satisfiability of the residual formula. `ExactVariableDeletionSAT` gives two ordinary unpaired languages. It uses the empty residual to test the structural domain, and the original formula as residual to decide SAT within that domain. Both use the reference syntax guard to reject malformed encodings. The shape statement writes deletion explicitly as a filter on each clause. An empty clause can remain on the structural side when reached by deletion, while its residual counterpart might have been satisfied by the branch and removed. The distinction is part of the checked semantics.

The Horn specialization counts positive occurrences among undeleted literals. The renamable Horn specialization uses the same count after applying the chosen global polarity flips. Each underlying guard is closed under taking sublists of clauses because each kept clause has its original Horn bound or the original renaming witness. The exact statements express the guard after filtering by the deletion list, with no altered definition of SAT or of `P`. They invoke the previously measured base guard and decision theorem rather than deciding the renaming or Horn subproblems by an unbounded search.

Each specialization also produces a sparse true-variable witness of encoded length at most that of the original input. Appended unit constraints cannot violate either counted clause bound, even after an arbitrary sign renaming. Hence every appended-unit query made by the earlier sparse solver is in the corresponding domain with the same deletion list and, for renamable Horn, the same renaming. The witness uses the original variable codes and evaluates to true on the original formula.
