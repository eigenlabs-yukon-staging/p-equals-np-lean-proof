# Indexed witness recovery and bounded Hamming repair

The main result of this package is a deterministic polynomial-time decider for a verifier with a polynomial-time witness predictor that is within a fixed Hamming distance of some accepted witness on each positive input. The locations of the incorrect bits can be anywhere in the predicted word. A separate theorem returns the first accepting witness from a uniformly polynomially indexed family, with exact success and exhaustion behavior. This package retains the previous indexed decision projection, the logarithmic suffix application, and the reference P contained in NP inclusion.

## Bit repair with measured computation

`MeasuredBitFlip` implements the pinned tagged pair input consisting of a unary index word and a Boolean word. It returns the exact `List.modify` operation that negates the selected bit. Internally the prefix is obtained by the pinned measured take primitive. The suffix is obtained by iterating the reference tail machine for the number of symbols in the index word. The emptiness tests on the suffix and its initial run of true symbols distinguish the three cases. An empty suffix contributes nothing, a suffix starting with false begins with the opposite true bit, and a suffix starting with true begins with false. Appending the untouched tail and prefix restores the original length. An index at or beyond the end leaves the word intact.

`BoundedBitRepair` builds a family of deterministic deciders indexed by the fixed number of repair rounds. The zero-round machine just verifies the current proposed witness. In the inductive step, the input state contains the original input and its current witness under the reference self-delimiting pair representation. The candidate generator decodes the state and applies one measured bit flip. The verifier for the generated candidate runs the previous-round decider on the resulting state. The clock has length one more than the current witness. Its extra round at index equal to witness length designates the identity operation, so a repair may use fewer than the fixed number of genuine flips.

The semantic proof uses the same decider on all raw input words via the total pair decoder. It clamps any out-of-range index in a proof schedule to the identity index before invoking the indexed projection. This yields exact equivalence with the existence of a list of the specified length whose left fold of bit modifications produces an accepted witness. The construction allows repeated indices. A schedule may undo an earlier change, which preserves the interpretation of the theorem.

`HammingCoveredVerifier` converts a Hamming-distance bound into such a repair schedule. For same-length words, a recursive proof chooses exactly the mismatched positions. It raises all indices of the tail schedule by one before applying it to a longer word, proving that this leaves the head untouched. If the head differs it is repaired first. Counting true entries of the zipped inequality list gives the exact length of the schedule. The proof pads a shorter schedule with out-of-range no-op indices after the target is reached. On the soundness side, the hypothesis that any accepted witness certifies membership directly justifies every successful repair.

The fixed error count is a parameter of the theorem and the machine construction, independently of the input. Each inductive layer invokes the preceding decider a polynomially bounded number of times. The proof gives no uniform polynomial bound for a repair count that grows with the input. It also requires a polynomial-time predictor and only applies the coverage premise when an accepted word exists at the predicted length within the stated distance. A polynomial bound on the absolute witness length supplies neither of those properties.

## Indexed recovery and prefix queries

`IndexedWitnessSearch` composes the verifier and candidate generator at each index as before, but emits one self-delimiting record for every success. The pinned polynomially measured range loop concatenates the records in increasing index order. The first record still decodes correctly with the subsequent records as a suffix, so the finishing machine emits a true tag followed by the first accepted witness. When every scheduled candidate fails it emits the empty word. The success case also covers the empty witness, since its record has a delimiter and the final output still has the success tag. This package proves exact ordering for arbitrary clock and generator functions at the reference types. The machine collects the scheduled successful records before choosing the first, so the proof does not require a short-circuit model.

The auxiliary results `PrefixExtensionNP` and `VerifierSearchFromPrefixDecider` isolate two steps of a general adaptive route. The first constructs an NP language that classifies extendible prefixes of a polynomially bounded verifier. The second assumes an explicit deterministic polynomial-time decider for that query language, and builds a witness selector with a polynomial clock. `VerifierSearchCollapse` connects the auxiliary steps to the familiar equivalence between the class equality and witness production. The earlier Yukon witness recovery developments already establish this general equivalence. The stepwise statements here expose the prefix language and the assumed deterministic decider independently. The new focus is the indexed first-success specification and the Hamming repair construction, neither of which assumes general prefix query decidability in P.
