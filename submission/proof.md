# SAT via a bounded 2-CNF variable-deletion backdoor

This submission gives a deterministic polynomial-time algorithm in the pinned Lean model for recognizing formulas that become 2-CNF when all occurrences of at most a fixed number of variables are deleted. On that domain it also decides satisfiability of the original formula and produces a sparse satisfying assignment for every satisfiable instance. Deletion removes literal occurrences and retains all clause positions, including clauses that become empty. The algorithm finds the backdoor internally. The input is the existing ordinary canonical CNF encoding, with no supplied variable list.

The bound `k` is fixed before the machine is constructed. The result applies to each natural-number bound separately. In particular, it permits many nonbinary clauses that share a small deletion set. It does not claim one polynomial bound with arbitrary encoded `k` or a deterministic polynomial-time decision procedure for all CNFs. It is a restricted SAT construction. The archive retains a checked `P ⊆ NP` theorem from an earlier submission, and contains no claim of the reverse inclusion.

## Structural search

Deleting the variables of a backdoor must hit at least one of the first three literal positions of every currently nonbinary clause. Those positions may include repetitions of a variable. If none of the three identifiers are deleted, the three positions all survive and violate the two-literal bound. This provides a branching set of at most three distinct identifiers without enumerating variables by numerical value. The formal proof uses the pinned `IsKCNF 2` predicate and the actual filtered list of literals. Its reverse direction puts the newly chosen variable at the start of a successful remaining deletion list. The forward direction removes one copy of the chosen identifier from a witnessed deletion list and checks that the filter after both erasures has exactly the same effect. The proof does not assume the witness list is ordered or duplicate-free.

At each nonbinary node the algorithm uses the existing measured clause packer to produce a reverse list of all nonbinary clauses. It inspects the first three positions of the first clause in that list and tries each identifier with both Boolean assignments. The structural input erases occurrences of that identifier from every clause. In parallel, the residual SAT input receives the chosen assignment. This operation drops satisfied clauses and erases the variable from every surviving clause. The two sign branches cover both choices of an arbitrary satisfying assignment to the residual formula. Conversely, an assignment satisfying a restricted formula lifts to one satisfying its parent by updating the chosen variable.

The theorem uses a pair of CNFs. The residual formula may be any sublist of the structural formula. Applying one assignment on the residual side and occurrence erasure on the structural side preserves the sublist relation, since restriction first removes clauses and then applies the same literal filter. When the structural formula becomes binary, the residual formula is therefore binary too. The machine calls the reference 2-SAT algorithm on the residual formula at that point. If the depth limit is reached with a remaining nonbinary clause it rejects. These are separate termination cases even when the residual is already empty. In the latter situation the structural side still has to certify that the domain has a small deletion backdoor.

## Measured computations and exact statements

`MeasuredTwoSATBackdoor` checks that the raw paired-input Boolean function is polynomial time and gives its precise meaning on canonical pairs under the sublist hypothesis. At every fixed successor depth, a finite composition of previously measured functions tries all six alternatives. Canonical literals are read at boundaries with the pinned first-literal and literal-drop operations. Occurrence erasure and both signed restrictions use the previously measured variable restriction operation. Their runtime proofs allow arbitrary input strings. The raw machine concatenates flags returned by its children and tests whether the result is nonempty, so there is no extra unrestricted search in the formal decider.

`ExactTwoSATBackdoor` checks two languages on the ordinary unpaired canonical formula string. In the first language the formula has a deletion backdoor of size at most the fixed bound. This decision runs the paired algorithm with an empty residual formula, so the residual is satisfiable throughout and only structural search determines acceptance. In the second language the same property holds and the original formula is satisfiable. This decision sends the input formula to both sides. Both wrappers intersect the machine result with the pinned canonical syntax guard. The theorem expresses the backdoor with an existential list of natural numbers bounded in length and occurrence filtering, using the pinned `IsKCNF`, `encodeCNF`, and `Satisfiable` definitions.

`TwoSATBackdoorSearch` returns a concatenation of canonical binary variable codes for the variables assigned true. The witness length is bounded by the encoded length of the original input, and evaluation using list membership for true variables satisfies the original input. This uses the earlier measured sparse search by appending unit constraints. The same deletion list continues to work after adding any number of unit clauses, since filtering a unit clause can only leave a unit clause or an empty one. The exact decision guarantee therefore applies to all of the sparse search's satisfiability queries. No scan of all identifiers up to the largest natural number is used.
