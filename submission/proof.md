# Deterministic bounded-multiplicity simulation with a promise decider

The statement starts with a language L, an original relation R with a pinned deterministic polynomial-time verifier, a witness length polynomial p, and a fixed natural number c. For each source input, membership in L is equivalent to existence of a witness in R of the prescribed length. The finite set of such witnesses is assumed to have at most c+1 members at every input. The theorem constructs a polynomial-time query verifier D and proves that any polynomial-time Boolean decider satisfying the stated zero-versus-unique promise for D gives a deterministic polynomial-time decider for L.

Each query attaches a pattern of c optional coordinate tests to a copy of the source. The index alphabet has a blank test and two tests for each coordinate in the fixed-width witness representation. The width is 2p(|x|)+1 and can be generated by the pinned polynomial clock on the source word. The worker constructs the alphabet in serialized form and applies a fixed number of bounded product operations. The record product correctness theorem proves that the emitted words contain all choices of c records from the alphabet. A query attachment machine adds the source word to each candidate pattern and the encoded list of attached queries is the output of a pinned polynomial-time transducer.

The verifier checks the original relation and witness length before testing the pattern. Thus for a source NO input all queries in the generated list have zero accepting witnesses. The assumed promise decider returns false for each and the list OR machine returns false. For a source YES input, select an existing bounded witness. The finite coordinate separation argument produces a pattern that isolates it, the product enumeration includes its code, and the promise decider must return true on that query. The list OR therefore returns true for the source. Other queries may have several witnesses, and the same proof works for any outputs of the promise decider in those cases.

The final deterministic machine uses the pinned encoded list scanner and one call to the promise decider per item as needed. Composition with the query generator supplies the pinned polynomial-time judgment. The hypothesis on c is important: an exponent growing with the source input would invalidate the use of a fixed number of polynomial-time products in this construction. The theorem applies to each verifier and each fixed c under the explicit cardinality bound. It does not give a bound for arbitrary NP witness sets.

The promise is solely a restriction on which answers a hypothetical measured Boolean function must give. The construction does not prove that such a function exists, and the actual theorem concludes conditional membership in P. The result strengthens a finite existence statement by proving that a deterministic machine can generate the necessary list on its own and by checking the reduction's soundness on all NO inputs and completeness on all YES inputs under the stated hypotheses.
