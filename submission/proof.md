# Measured reverse unit propagation and refutation checking

This submission constructs a deterministic polynomial-time verifier for the pinned reverse unit propagation relation and for newest-first RUP learning runs. The input uses the reference encoding of a CNF and a proposed sequence of learned clauses. The exact refutation verifier rejects malformed encodings, accepts exactly learning runs with an empty learned clause, and is proved sound for the reference satisfiability predicate. The construction does not assume a polynomial bound on the lengths of all RUP refutations. It measures the verification computation in the length of the formula and proposed trace together.

The exact theorem uses `PEqualNP.Search.IsRUP` and `PEqualNP.Search.IsRUPRun`. These definitions use finite sets of literals for clauses, while the reference SAT encoding uses lists. The proof transfers each encoded clause to its finite set and proves that the literal scans implement that set semantics, including duplicated literal occurrences. It preserves the exact variables and signs from the pinned encodings. No variable array indexed up to the largest natural number is constructed.

## Measured unit propagation

To check whether a clause is RUP, initialize the list of known true literals with the complements of the proposed clause's literals. Each propagation round then reconstructs the list from the original assumptions plus those literal occurrences forceable by some original clause under the previous known list. In a clause, a proposed forced literal is exempted by literal equality throughout the clause. All other literals must have their complements among the known truths. This equality exemption is important when a literal occurs repeatedly. For example, two copies of the same literal both represent one member of the finite-set clause.

`MeasuredUnitRound` uses the earlier measured literal and clause scans and the pinned encoded-literal comparisons. An outer clause scan shares the current known list, an inner literal scan proposes each candidate, and a scan of that clause detects a disqualifying other literal. The implementation emits only canonical literal records of forceable occurrences. It never appends an unbounded historical list of repeated derivations. A separate measured scan tests whether some original clause has every literal falsified by the resulting known list. That scan treats the empty clause correctly because the all-literals condition is vacuous.

The pure proof establishes soundness by induction on propagation rounds. An emitted literal is either assumed true or has a reason clause whose other finite-set members have their complements derivable in earlier rounds. For completeness, inclusion of the known sets is preserved from one round to the next. All known literals lie in the fixed finite set of assumption literals and formula occurrences. If a round's known set strictly grows, its finite-set cardinality grows by at least one. Once two consecutive sets agree, future rounds also agree. Therefore the number of input literal occurrences including assumptions suffices for closure. Induction on the pinned `UPForces` derivation proves that every derivable literal belongs to that fixed point.

The raw machine runs for the length of the paired input. On canonical inputs that length bounds the number of literal occurrences used by the pure completeness argument. The bit-string state holds the fixed formula, fixed assumptions and the reconstructed known list. The latter is clipped to the original size cap. The pure sublist bound proves clipping is inert on canonical runs, since the assumptions and potential emitted occurrences are all represented by already present variable codes. Runtime and size bounds hold on arbitrary raw inputs. After closure the machine checks for a fully falsified original clause, matching the pinned definition of RUP. The verifier does not substitute a different test for that last step, even when input assumptions contain both signs of a variable.

## Exact learning runs and soundness

`MeasuredRUPRun` checks a learning sequence in newest-first order. For each indexed clause of the sequence it checks that clause against the original formula concatenated with the sequence suffix that follows it. This suffix contains exactly the older learned clauses in the paired relation. Measured first-clause extraction identifies each candidate and its suffix, with encoded length as a bound on the number of iterations. The correctness induction follows the constructors of the pinned learning relation. The empty learning sequence is valid as a run, while it cannot pass the additional refutation requirement.

`ExactRUPRefutationVerifier` adds canonical syntax checks for both strings and checks that the trace contains an empty clause. It then proves semantic soundness separately. Unit propagation preserves truth in any assignment satisfying all the relevant clauses and hypotheses. A RUP clause is therefore true in every assignment satisfying all previous clauses, since assuming that it is false would force some already satisfied clause to be false. Induction over the exact learning run preserves satisfiability under its learned clauses, so accepting an empty learned clause excludes every satisfying assignment for the original CNF.

`ExactUnitRefutableCNF` establishes membership in the reference `P` class for the exact canonical language refutable with no initial assumptions. It calls the measured RUP test with the empty proposed clause. `HornUnitRefutation` additionally proves that an unsatisfiable Horn CNF has such a unit refutation. Its proof uses the assignment that makes precisely the forced positive variables true. If all negative literals of a Horn clause are false under that assignment, a unique positive literal must be forced, or the clause is entirely falsified. Thus a Horn formula with no propagation conflict is satisfiable.

## Certificate languages and replay

`BoundedRUPRefutationsInNP` states that the language of canonical formula encodings having a valid refutation whose encoded length obeys a fixed natural-coefficient polynomial bound belongs to the pinned class `NP`. The witness is the canonical trace encoding, and the bound is on that encoding's bit length. `RUPCoverageCoNP` proves a conditional upper bound. If all unsatisfiable canonical inputs meeting a specified measured guard have such polynomially bounded RUP traces, the guarded SAT language belongs to the pinned `coNP`. Its complement verifier also handles malformed strings and inputs outside the guard, which can use an empty witness. These are certificate-verification and coverage results. They do not assert general resolution or RUP proof-length upper bounds, unrestricted SAT in P, or a collapse of NP and coNP.

The earlier clause and literal map constructions and exact parser are reused, with honest declared dependencies. The pinned reference provides the finite-set proof-system statements and the complete-literal parsing and membership primitives. New sources contain the exact finite fixed-point argument, measured propagation and suffix traversal, trace soundness, and the certificate class results. The archive retains the earlier independent reference inclusion `P ⊆ NP`.
