# Uniform polynomial branch budgets for 2-CNF variable deletion

This development gives a single measured deterministic solver for each fixed unary polynomial clock. On a canonical CNF of encoded length `n`, it recognizes the class with a 2-CNF variable-deletion backdoor of size at most some `k` with `6^k ≤ q(n) + 1`. It decides satisfiability of the original input on that class and produces a sparse satisfying assignment of length at most the input length whenever one exists. Here `q` is any fixed polynomial over the naturals. The permitted deletion depth can grow logarithmically with the encoded input length. The machine does not require the deletion set, an assignment to that set, or the appropriate depth as part of the input.

The earlier bounded-depth algorithm built a different finite composition of six child computations for each fixed depth. The new result uses one uniform walk and an outer polynomial enumeration of ranks. The exact theorem remains about a restricted class of formulas. It makes no claim that all CNFs have such backdoors, that unrestricted SAT is in P, or that P equals NP. The retained reference inclusion is a separate theorem.

## A rank describes a whole branch

At a nonbinary structural formula, any deletion backdoor has to remove the variable in at least one of the first three positions of a nonbinary clause. The algorithm picks the first such clause in the reverse list supplied by the earlier measured clause packer. The three possibilities may contain a duplicate variable identifier. Trying all three is still complete. For each identifier both true and false are possible values for satisfying assignments to the residual formula. These choices give at most six alternatives per step.

The branch rank is read least-significant digit first in base six. Digits zero through two select the three positions with the value true. Digits three through five select the same three positions with the value false. At each step the unary available budget and the unary rank are both divided by six. The rank remainder selects the action, and its quotient is the rank for the child. The solver takes a step only if the budget is at least six and the structural formula still has a nonbinary clause.

The structural formula erases every occurrence of the selected variable but retains even empty clauses. The residual formula is restricted by the assigned value, which removes clauses containing the selected literal and deletes all remaining occurrences of the variable. The residual starts as a sublist of the structural formula and remains a sublist of the new structural formula after each step. When the structural formula becomes binary, so does the residual, and the measured reference 2-SAT decider can decide the latter. If the budget is exhausted with a nonbinary clause still present, that path rejects.

The pure proof gives both directions of the rank enumeration. For soundness, each successful nonterminal step spends a factor of six, and a successful tail of depth `k` gives a witness of depth `k+1` at its parent. Satisfiability of the residual lifts along every successful restriction by updating the selected variable. For completeness, the three-position lemma gives a position contained in a witnessed deletion list, and a satisfying assignment gives a Boolean value for that variable. The child budget is the parent budget divided by six. A successful child rank `j` and desired digit `d` yield the parent rank `6*j+d`. The proof uses the quotient bound to show this rank is strictly below the parent budget, including when the parent budget is not a multiple of six. If the structural formula is already binary and the residual satisfiable, rank zero works for every positive budget. A successful path uses no encoded numerical bound on variable indices.

## Measured walk and exact language

`MeasuredRankedBackdoorWalk` proves a polynomial-time Boolean function of a packed raw input containing a unary budget, unary rank, and the two CNF encodings. Its exact statement quantifies over a positive budget and a residual formula that is a sublist of the structural one. An accepting rank below the budget exists exactly when the residual formula is satisfiable and there is a deletion depth whose power of six fits the budget. The theorem uses the pinned canonical CNF encoding. The recorded standalone statement writes the raw pair as the unary length of its first field, then a false separator, then the two fields. This is definitionally the pair operation used by the reference machine library.

The raw loop runs for the length of the supplied budget, so it always has enough iterations to exhaust every admissible chain of divisions by six. Successful and exhausted states are fixed points of the loop. The state uses an immutable size cap determined by its initial packed input. Each updated credit, rank, and formula field is clipped at that cap. The correctness proof shows the clipping is inert on canonical walks, because both unary numbers decrease and both formulas have nonincreasing encoded length. The raw length and stable-measure inequalities are valid even on malformed strings. The measured runtime follows from bounded iteration, the measured division and remainder, and finite composition of the pinned and locally checked functions.

`ExactPolynomialBudgetTwoSATBackdoor` proves that two exact canonical languages belong to the reference class `P`. The first is the domain given by the deletion and budget property, obtained by running the walk with an empty residual formula. The second is the satisfiable subset, obtained by starting both sides at the same formula. Each construction uses a polynomially bounded indexed scan of ranks and the pinned canonical syntax guard. The fixed polynomial sets the budget `q(n)+1`, so the scan always allows rank zero. The algorithm never computes `6^k` as a unary integer. That expression occurs in the correctness specification and the arithmetic proof.

`PolynomialBudgetTwoSATBackdoorSearch` gives a measured sparse true-variable encoding for each satisfiable input in the class. Appending unit constraints cannot increase the width of clauses in the deletion test beyond two. It also cannot shrink the encoded input, and a natural-coefficient polynomial is monotone on the natural numbers. Therefore the same deletion witness still fits the budget on every appended-unit query. This allows the earlier sparse SAT search to use the new exact decision procedure throughout. The solver's output length bound is inherited from that search theorem and verified against the original encoded input.
